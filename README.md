# 我的视觉图鉴

在线使用：**https://kate19960208.github.io/motion-atlas/**

按照“风格库与动效库分开积累，再叠加个人指纹”的方式制作的中文视觉参考图鉴。

## 包含什么

- **414 条动效、镜头和光影参考**：264 条 Motion Prompt 动态实现与运动规范，150 条 Video Shotcraft 动态样例。
- **114 条视觉风格参考**：99 种 Lemo-Opuscar 目录与参考画面，15 套 MG Styles 15 风格与原作提示词。
- 中文检索、分类与来源筛选，动态预览按可见范围播放。
- 详情中保留运动参数、原作链接、许可、可复制提示词和个人备注。
- 收藏、自建参考、组合方案，支持 JSON 导出、导入与按编号合并。
- 组合工作台：主要风格、辅助风格、动作、个人配色、字体和固定元素，输出给 Codex 的制作要求。

资料快照：2026-11-25。上游项目会继续更新，网页显示的是本仓库保存的快照。

## 按原视频的方法使用

1. 在“视觉风格”选画面的视觉语言，收藏喜欢的风格。
2. 在“动效与光影”选动作，查看时序、缓动、方向与适用场景。可用去色预览观察运动。
3. 在详情写自己的备注：为什么喜欢，准备放在哪一段，哪些地方要调整。
4. 在“组合工作台”选一到两种风格与动作，加入自己的配色、字体和个人元素。
5. 复制组合提示词给 Codex：先用简单形状做运动白模，再套风格，先检查短样片。
6. 把实际用过的方案保存下来，定期导出备份。

去色预览保留原作形状和文字，不等同于把任意视频自动拆成干净的运动骨架。白模化的重新实现写在组合制作要求中，需由制作工具完成。组合预览只演示所选动作；它不会假装已经渲染出两套风格混合后的成片。

## 保存在哪里

- 网页源码、基础目录与 Motion Prompt 实现保存在这个 GitHub 仓库，通过 GitHub Pages 发布。
- **收藏、备注、自建参考、组合方案和个人配色保存在当前浏览器的 localStorage**，不会自动同步到 GitHub，也不会自动跨设备同步。
- “备份与导入”可以导出 JSON 并带到另一台设备。导入按稳定编号合并，不覆盖已有备注。
- 网站不需要 API Key 或 GitHub Token。不要把秘密、账号凭证放进公开仓库。
- 外链视频和部分图片保留在原作站点，播放受源站和网络状况影响；没有将数百条视频重新打包到仓库。

## GitHub Pages 部署

仓库 Settings → Pages → Build and deployment：

1. Source 选择 **Deploy from a branch**。
2. Branch 选择 **main**，目录选择 **/(root)**，保存。
3. 部署完成后打开上方在线网址。

这是纯静态 HTML / CSS / JavaScript 项目，不需要 Node 构建、数据库或额外服务器。

## 开发预览

有 Node.js 时，在仓库目录运行 `node server.mjs`，打开打印的本地地址。

## 维护

- `data.js`：统一条目目录，稳定编号由“来源 + 原作编号”组成。
- `app.js`、`app.css`、`index.html`：界面与个人收藏功能。
- `runtime.js`、`motion-samples.js`、`motion-artstyle.js`：原作 Canvas 实现，保留 MIT 署名；artstyle 的画面从原作域名读取。
- `LICENSE-*.txt`、`THIRD_PARTY_NOTICES.md`：第三方许可与来源说明。
- 在界面中添加的参考是个人浏览器数据。需要永久加入公开基础库时，可把经核对的条目加入 `data.js` 并提交到 GitHub。
